tuple has exactly 8 elements (matches the 8 indexed columns of
the FTS5 virtual table). Validate `snippet_column` is one of
the eight column names.

* **File:** `src/doc3gpp/settings/schema.py`
* **Test:** `tests/unit/test_search_settings.py` (new)
* **TDD pair:**
  1. Write 4 tests:
     - `test_bm25_weights_default_is_eight_floats`
     - `test_bm25_weights_rejects_wrong_length`
     - `test_snippet_column_default_is_title`
     - `test_snippet_column_rejects_unknown_column`
  2. Run to verify failure.
  3. Add the two fields + a `field_validator("bm25_weights", ...)`
     that raises `ValueError` when length != 8.
  4. Run to verify pass.
  5. Commit `feat(search): add bm25_weights + snippet_column settings`.

Defaults (from spec):

```python
bm25_weights: tuple[float, ...] = (
    10.0, 1.0, 0.5, 0.5, 2.0, 4.0, 3.0, 3.0,
)
snippet_column: Literal[...] = "title"
```

Column order (matches `tdoc_search` DDL):

```python
_SNIPPET_COLUMN_NAMES: tuple[str, ...] = (
    "title", "ftp_url", "meeting_title", "meeting_location",
    "wis", "cover_text", "change_text", "ttcn_text",
)
```

## Task 2: Repository — weighted BM25 + explicit ORDER BY

Update `SQLAlchemySearchIndexRepository` to:
- Cache `bm25_weights` and `snippet_column` from `get_settings()`
  in `__init__`.
- Use `bm25(tdoc_search, w0, ..., w7)` (parameterized) in
  both the SELECT and the ORDER BY.
- Resolve `snippet_column` name to FTS5 1-based column index
  and pass that + `snippet_tokens` to `snippet(...)`.

* **File:** `src/doc3gpp/storage/repositories/search_sql.py`
* **Test:** `tests/integration/test_search_weighted_bm25.py` (new)
* **TDD pair:**
  1. Write 3 tests:
     - `test_title_weight_outranks_meeting_title` — index 2
       rows: row A with "alpha" only in `title`, row B with
       "alpha" only in `meeting_title`. Query `alpha`,
       assert A comes first.
     - `test_default_weights_applied_when_settings_unchanged`
       — same as above but uses default settings (no
       override).
     - `test_explicit_order_by_bm25_used` — inspect the
       SQL the repo constructs (capture via
       `engine.connect()` + `before_cursor_execute` event
       or by mocking `conn.execute`).
  2. Run to verify failure.
  3. Update `__init__` and `search()`.
  4. Run to verify pass.
  5. Commit `feat(search): use weighted BM25 with explicit ORDER BY`.

The FTS5 1-based column index for `tdoc_search` is:

```
1: tdoc_id (UNINDEXED — counted but not searched)
2: title
3: ftp_url
4: meeting_title
5: meeting_location
6: wis
7: cover_text
8: change_text
9: ttcn_text
```

So `snippet(tdoc_search, 2, ...)` = title snippet.

     `snippet_tokens: int | None = None` override.
  4. Run to verify pass.
  5. Commit `feat(search): wire --explain + per-call snippet_tokens override`.

## Task 4: Composite indexes for filter push-down

Add three composite indexes via `_create_search_schema()`:

```sql
CREATE INDEX IF NOT EXISTS idx_tdocs_release_spec
    ON tdocs (release, spec);

    ON tdocs (uploaded_date);
CREATE INDEX IF NOT EXISTS idx_meetings_name_tsg
    ON meetings (name, tsg);
```
