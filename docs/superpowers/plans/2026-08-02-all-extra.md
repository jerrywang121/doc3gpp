# `[all]` Install Extra Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `doc3gpp[all]` optional extra so one `pip install "doc3gpp[all]"` installs every runtime extra (cli, extract, search, semantic).

**Architecture:** One new entry in `pyproject.toml [project.optional-dependencies]` that aggregates the four runtime extras via PEP 508 self-references (`doc3gpp[<name>]`), plus documentation of the new install target in README.md, AGENTS.md, and docs/cli.md. No runtime code changes.

**Tech Stack:** hatchling (build), PEP 508 optional-dependencies, tomllib (verification).
